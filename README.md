# NiceVPN

Personal Android client for VPN Gate public relay servers.

## Current milestone

This repository starts with a VPN Gate server directory and OpenVPN profile export. The app does not yet claim a tunnel is connected. A verified tunnel integration is the next milestone.

VPN Gate relays are operated by volunteers. Availability and each relay's logging policy can differ. Do not treat this service as a private VPN.

## Build

The project uses Android Gradle Plugin 9.4.0, Gradle 9.6.0, JDK 17, and Android SDK 36. CI builds a debug APK and runs parser unit tests.
